# Advatar advertiser portal · team demo

Static build of the Advatar advertiser portal for walkthroughs: **https://jordanwcy.github.io/advatar-portal-demo/?lang=zh-CN**

Everything runs in your browser (fixtures + localStorage), nothing is sent anywhere. No real screens, payments or advertisers.
Source lives in the private `advatar-vision` repo, branch `codex/advertiser-portal`, directory `portal/` (`npm run build:static`).
